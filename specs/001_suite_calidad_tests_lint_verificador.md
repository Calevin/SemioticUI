# Verificador Programático — suite_calidad_tests_lint (Spec 001)

> **Contrato Inmutable (`seb-harness`):** `.seb/bin/seb verify suite_calidad_tests_lint` ejecuta este archivo; es la única fuente de verificación de la tarea.
> **Prohibición Anti-Reward-Hacking:** el agente implementador tiene terminantemente prohibido editar este archivo o relajar los tests que invoca.
> **Precondición:** se ejecuta desde la raíz del repositorio y dentro del dev shell (`nix develop` o direnv), con `npm install` ya ejecutado. Los comandos usan solo sintaxis POSIX `sh` y no contienen el carácter de tubería, para no romper el parseo de la tabla.

## 2. Criterio de Aprobación

- La tarea solo se considera implementada cuando `.seb/bin/seb verify suite_calidad_tests_lint` reporta el **100 % de los controles (`001-CHK-01` a `001-CHK-31` y `001-CHK-99`) en estado `[PASA]`**.
- Ningún control puede omitirse, desactivarse ni condicionarse a variables de entorno.
